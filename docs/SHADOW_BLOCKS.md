# Shadow Blocks

Tap a square to add a block. Each row and column casts a shadow as high as its tallest stack. In both panels, make **Your shadow** match **Goal**. Use all the blocks.

Start with **First shadow**. Tap the gold square once at A1, then twice at B2. Watch the purple squares appear under **Your shadow** as you add blocks.

| Action | Control |
| --- | --- |
| Place a block | Tap a square or choose a stack and press **+** |
| Take a block away | Choose a stack and press **−** |
| Check the shadows | Compare the current and target shapes |
| Move the camera | Choose **Rotate** and drag |
| See examples | Press **See example** beside the shadow panels |

Choose one of eight levels or start a random Easy, Medium, or Hard puzzle. The larger boards have taller stacks. Hint places or removes one block. Undo reverses the last edit. Retry keeps the layout. Progress is saved in this browser.

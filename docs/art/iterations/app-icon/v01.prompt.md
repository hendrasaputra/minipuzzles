# App icon v01: render request

Rendered, not generated: this repository had no GPT Image tool in the session, so the installable app icon is a Three.js render that follows the shared style contract in [ICON_STYLE.md](../../ICON_STYLE.md).

- Subject: the collection itself. A rimmed ivory ceramic 3×3 puzzle tray with a raised blush-pink block (back), a taller dusty-blue block (right), muted sage and blush floor tiles, and a brass marble on the front-centre tile. No text or logos.
- Camera: orthographic, 30° elevation, 45° yaw.
- Light: warm key from the upper left, soft lower-right contact shadow (PCF soft shadows), soft room environment for satin ceramic and brass.
- Backing: opaque warm-ivory diagonal gradient with a soft upper-left glow. iOS and Android apply their own corner masks.
- Outputs: `v01.png` (1024², full) for iOS and the "any" manifest icon. `v01-maskable.png` (1024², miniature at 84% scale) for Android's maskable icon.

Source: [v01.render.html](v01.render.html). To render again, serve it from a folder that also holds `three.module.js`, `three.core.js` (from `node_modules/three/build/`), `RoundedBoxGeometry.js` and `RoomEnvironment.js` (from `node_modules/three/examples/jsm/`, with their `'three'` import pointed at `./three.module.js`), and accept its POSTed PNGs.

# Garden Keys v01: render request

This icon is rendered, not generated. The session had no GPT Image tool. The connected Canva image tool only accepts the user's own words as its prompt, which is too little to carry the family style. So the icon is a Three.js render that follows the shared style contract in [ICON_STYLE.md](../../ICON_STYLE.md), like the [installable app icon](../app-icon/v01.prompt.md).

- **Subject:** a thick painted-wood garden tray with three by three moss tiles. It shows the game's main pieces as large, readable objects:
  - leafy hedge blocks along the back and left edges, which are the maze walls;
  - a blush arched door with a brass knob in an ivory frame, on the back-right square, turned to face the viewer;
  - an oversized brass key lying across the centre;
  - a soil burrow mound with a dark arched entrance, front-right;
  - a seed with a sprout, front-left.
  
  There is no text and no logo.
- **Camera:** orthographic, 30° elevation and 45° yaw.
- **Light:** warm key light from the upper left, PCF soft shadows, and a soft room environment for satin paint and brass. There is no ground plane, because its shadow ran past the render square.
- **Backing:** the shelf's opaque peach ceramic tile, sampled from the GPT icons. The rim is #fde7d0, fading to #eec7a0 at the lower right. The field is #f9d9b7 to #fbe1c4, with a soft upper-left glow. The miniature is drawn at 93% scale. The display applies the 26% rounded mask.
- **Output:** `v01.png`, 1024×1024.

**Source:** [v01.render.html](v01.render.html). To render it again, serve it from a folder that also holds:
- `three.module.js` and `three.core.js`, from `node_modules/three/build/`;
- `RoundedBoxGeometry.js` and `RoomEnvironment.js`, from `node_modules/three/examples/jsm/`, with their `'three'` import pointed at `./three.module.js`.

The folder must also accept the PNG the page POSTs.

# Robot Garden

Collect every seed and stop on the dock.

1. Tap arrows to add commands. The robot moves one square per command.
2. Press **Run** to play the commands in order.
3. If a rock or edge stops the robot, change the commands and run again.

The first garden takes two commands. Move east to pick up the seed, then north to reach the dock. Open **See example** beside the board to see the route.

Undo removes the last command. Clear empties the command list. Hint helps you add a step toward the goal. Rotate turns the 3D view. The commands stay tied to the board as you look around.

Choose from eight levels or start a seeded Easy, Medium, or Hard garden. Larger gardens have more seeds and rocks. Reload restores the command list and completed levels.
